# ORGANISM-INTERFACE

Русский: Единый интерфейс организма: наблюдение, управление, архитектура, граф, память, эксперименты, восстановление и взаимодействие с органами.

English: Unified organism interface for observation, control, architecture, graph, memory, experiments, recovery, and interaction with organs.

中文：统一的有机体接口，用于观测、控制、架构、图谱、记忆、实验、恢复以及与各个器官的交互。

---

## Назначение / Purpose / 用途

`ORGANISM-INTERFACE` — это интерфейсный слой между человеком, внешними интеллектуальными системами и организмом SPACE.

Он не является самим организмом, не заменяет Foundation и не определяет внутренний язык органов. Его задача — дать единое место и единый способ **видеть, понимать и взаимодействовать** с различными частями системы.

The interface is the interaction layer between humans, external intelligent systems and the SPACE organism. It is not the organism itself, does not replace the Foundation, and does not define the internal organ language.

该仓库是人与外部智能系统以及 SPACE 有机体之间的交互层。它本身不是有机体，不替代 Foundation，也不定义器官内部语言。

## Главная идея

Разные пользователи и разные интеллектуальные системы должны иметь одну понятную точку входа в организм, даже если внутри организма существуют разные органы, модели и механизмы.

```text
                    ORGANISM-INTERFACE
                            │
          ┌─────────────────┼─────────────────┐
          │                 │                 │
       OBSERVE           WORK WITH          OPERATE
          │                 │                 │
       state             research          approved
       memory            analysis           actions
       graph             experiments       interaction
       history           proposals
          │                 │                 │
          └─────────────────┼─────────────────┘
                            │
                       SPACE organs
```

## Основные области интерфейса

### 1. Observation — Наблюдение

Просмотр того, что организм показывает наружу:

- текущее состояние;
- доступные органы;
- связи между органами;
- граф;
- память и опубликованная история;
- результаты исследований;
- состояние экспериментов;
- доступные внешние данные.

### 2. Architecture — Архитектура

Представление структуры организма:

- Foundation;
- уровни системы;
- органы;
- связи;
- зависимости;
- интерфейсы органов;
- точки входа и выхода;
- состояние архитектуры.

Интерфейс показывает архитектуру, но не является её источником истины.

### 3. Graph — Граф

Единое представление элементов и связей:

- узлы;
- рёбра;
- отношения;
- маршруты;
- состояния;
- изменения графа;
- история изменений.

### 4. Memory — Память

Работа с доступной через интерфейс памятью:

- записи;
- события;
- результаты;
- исследования;
- история;
- происхождение данных;
- связанные материалы.

### 5. Experiments — Эксперименты

Интерфейс для работы с исследованиями:

- постановка вопроса;
- описание эксперимента;
- исходные условия;
- выполнение;
- наблюдения;
- результаты;
- сравнение;
- воспроизводимость;
- следующие шаги.

Экспериментальная работа должна быть отделена от канонического состояния организма.

### 6. Recovery — Восстановление

Представление доступных средств восстановления:

- точки восстановления;
- версии;
- состояние;
- результаты проверки;
- история восстановления;
- доступные действия восстановления.

### 7. Organs — Органы

Единая точка взаимодействия с органами:

- обнаружение органа;
- описание его назначения;
- входы;
- выходы;
- текущее состояние;
- доступные операции;
- результаты;
- связи с другими органами.

Конкретный внутренний протокол обмена между органами будет определён отдельным исследованием и здесь пока не фиксируется.

### 8. Human / AI Interaction — Человек и AI

Интерфейс должен быть пригоден для:

- человека;
- LLM;
- локальной модели;
- агента;
- исследовательского инструмента;
- другого программного интерфейса.

Все они должны иметь возможность пользоваться одной картой организма, не требуя от каждого отдельного пользователя знать внутреннее устройство каждого органа.

## Два уровня взаимодействия

### Guest / External — внешний уровень

Для знакомства и работы с опубликованной частью организма:

- обзор;
- чтение;
- наблюдение;
- анализ;
- исследования;
- работа с доступными материалами.

### Internal / Operator — внутренний уровень

Для уполномоченной работы с интерфейсом организма:

- расширенное наблюдение;
- работа с органами;
- управление доступными функциями;
- эксперименты;
- диагностика;
- восстановление;
- инженерная работа.

Точные права каждого уровня определяются отдельно от интерфейса.

## Инженерный режим

Для разработчика и архитектора интерфейс должен давать отдельное представление:

```text
ORGANISM
├── Architecture
├── Organs
├── Graph
├── State
├── Memory
├── Experiments
├── History
├── Recovery
└── Interfaces
```

Инженерный режим предназначен для сборки, исследования и диагностики системы, а не для сокрытия архитектуры за пользовательским интерфейсом.

## Рабочая модель

Типовой путь работы:

```text
ENTER
  ↓
DISCOVER
  ↓
OBSERVE
  ↓
UNDERSTAND
  ↓
SELECT ORGAN / AREA
  ↓
WORK
  ↓
RESULT
  ↓
HISTORY / NEXT STEP
```

Для исследования:

```text
QUESTION
  ↓
CONTEXT
  ↓
EXPERIMENT
  ↓
OBSERVATION
  ↓
RESULT
  ↓
REVIEW
  ↓
HISTORY
```

## История работы

Интерфейс должен позволять видеть не только текущее состояние, но и путь, которым система к нему пришла:

```text
past → events → states → current state
```

Это необходимо для понимания, проверки и продолжения работы.

## Внешний след

Работа человека или внешней LLM может иметь собственную историю, связанную с организмом, но эта история должна быть представлена как внешний рабочий материал, а не как незаметное изменение внутреннего состояния организма.

Для этого используется отдельное пространство внешних материалов в соответствующем публичном контуре.

## Что здесь НЕ определяется

Этот репозиторий намеренно не является местом для:

- определения Foundation;
- изменения канонической архитектуры;
- хранения внутреннего языка органов;
- объявления гипотез доказанными;
- подмены Core его интерфейсом.

Сначала строится и проверяется интерфейс. Затем отдельно исследуется и фиксируется язык внутренних органов.
